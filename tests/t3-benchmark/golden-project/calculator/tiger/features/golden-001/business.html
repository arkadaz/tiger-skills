Business: Four-operation calculator module

id: golden-001 grilled: 2026-06-18 stage: grill recommendation: go approval gate: lives in spec.html

Problem / Opportunity

The Tiger harness benchmark project has no reusable arithmetic module. Developers inline arithmetic ad hoc, making the codebase harder to test and maintain. A single, tested src/calculator.py module eliminates that duplication and provides a clean, importable contract for the four basic operations.

Target Users

WhoContextVolume / frequency
Developers on the Tiger benchmark projectNeed arithmetic in numeric utilities; currently inlining itAll benchmark runs; every feature that touches arithmetic

Value & Business Outcome

Shipping a reusable arithmetic module retires the duplication risk and provides the benchmark harness with a concrete, testable feature to run the full pipeline against. The capability unlocked is a verified, importable module that the T3 benchmark can use as ground truth for the code-generator, security, reviewer, and e2e gates. No revenue impact; internal tooling value only. We are suited to do it because the scope is exactly one file.

Key Rules Summary

RuleOne-line statement
BR1All four operations are pure functions with no external dependencies.
BR2Division by zero raises ZeroDivisionError — never swallowed.

Metric

  • Primary metric: all_operations_pass — baseline: 0 tests → target: 4 operations pass (increase)
  • Measured how: python3 -m pytest src/ -q run by the e2e gate; pass/fail recorded in the board's acceptance_criteria evidence.

Risks

RiskLikelihoodMitigation
Scope creep — adding a fifth operation or a CLIlowExplicitly out of scope in spec.html; ADR-001 is final for this feature.
Test coverage gap on edge cases (zero, negatives)lowE2E case E5 covers divide-by-zero; TDD mandate covers negatives.

What We Are NOT Doing

  • Floating-point precision beyond Python defaults.
  • Complex numbers, modular arithmetic, or any operation beyond the four basic ones.
  • CLI interface, REPL, or web API.
  • Persistent state (history, accumulator).
